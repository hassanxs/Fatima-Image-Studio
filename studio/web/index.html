      STORED ON THIS PC

      Models

      Downloaded from Hugging Face

      Each model is a few GB. Text encoders and VAEs that models share are only downloaded once, and kept while any model uses them.

      Upscalers

      Real-ESRGAN · BSD-3

      Make finished images 2× or 4× bigger. Small downloads; get the ones you want.

      LoRA library

      Style & character add-ons

      A LoRA is a small add-on file (usually 20–400 MB) that teaches a model a specific art style or character. Each one only works with the base model it was trained for — that's detected from the file. FLUX.2 LoRAs are adjusted on import so every layer applies in this engine.

      Agents (MCP)

      Claude Code · Codex · Antigravity · Hermes

      AI agents can drive Fatima Image Studio through MCP: make batches, wait for them, check the images, fix weak ones, upscale and export. They can't download models or delete anything, and they only save to the Exports folder.
